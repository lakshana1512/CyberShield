 CyberShield
 An All-in-One Digital Safety Platform

 About the Project
CyberShield is a web-based digital safety awareness platform that helps users understand common online threats and learn safe digital practices.

Problem Statement
People may face online scams through suspicious messages, fake job offers, malicious links, UPI fraud attempts, and identity misuse.

 Objectives
- Create awareness about common cyber threats.
- Help users identify suspicious warning signs.
- Provide basic digital safety guidance.
- Encourage users to verify information through official sources.

 Key Modules
1. Scam Message Checker
2. Voice Scam Awareness
3. Job & Website Checker
4. Suspicious Link Checker
5. UPI Safety Assistant
6. Identity Misuse Support

 Technologies Used
- HTML
- CSS
- JavaScript

 Testing
The prototype was manually tested using sample inputs.

| Module | Test Scenario | Actual Result |
|---|---|---|
| Scam Message Checker | Suspicious prize message | Risk Score: 90/100 – High Risk |
| Scam Message Checker | Normal message | Risk Score: 0/100 – Low Risk |
| Voice Scam Awareness | Open voice module | Safety guidance displayed |
| Job & Website Checker | Job offer requesting registration fee | Risk Score: 30/100 |
| Suspicious Link Checker | HTTP example URL | Risk Score: 30/100 |
| UPI Safety Assistant | Open UPI safety module | UPI safety advice displayed |
| Identity Misuse Support | Fake profile scenario | Reporting guidance displayed |

 Accessibility Checks
- Keyboard navigation checked.
- Button navigation using Enter key checked.
- Text readability checked.
- Mobile display checked.

 Limitations
- Uses basic rule-based checks.
- Does not confirm whether content is genuinely fraudulent.
- Does not analyse audio recordings.
- Requires further testing and development.

## Disclaimer
CyberShield is an educational awareness prototype. Always verify suspicious information through official sources.

## Conclusion
CyberShield provides basic digital safety awareness and guidance to help users identify suspicious activities and follow safer online practices.
