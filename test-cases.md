# CyberShield – Testing Report

Project Name
CyberShield – All-in-One Digital Safety Platform

Testing Method
Manual Functional Testing

 1. Scam Message Checker
Test Input: Suspicious prize message.

Expected Result: Identify suspicious warning signs.

Actual Result: Risk Score 90/100 – HIGH RISK.

Status: PASS

2. Voice Scam Awareness
Test: Open Voice Scam Awareness module.

Actual Result: Displays audio analysis limitation and advises users to verify emergency calls through trusted numbers.

Status: PASS

 3. Job & Website Checker
Test Input: Fake job offer requesting a registration fee.

Actual Result: Risk Score 30/100. Identified job registration or processing fee.

Status:PASS

 4. Suspicious Link Checker
Test Input: http://example.com/login?verify=account

Actual Result: Risk Score 30/100. Identified unencrypted HTTP connection.

Status: PASS

 5. UPI Safety Assistant
Test: Open UPI Safety Assistant.

Actual Result: Displays guidance not to share UPI PIN or OTP and not to enter PIN to receive money.

Status: PASS

 6. Identity Misuse Support
Test Input:Fake social media profile using someone's name and photo.

Actual Result: Advises saving profile links and evidence and reporting impersonation through the platform.

Status: PASS

 Testing Summary
All six modules were manually tested. Each module displayed the expected response during testing.

Limitations
- This is an educational prototype.
- Risk scores are based on basic rule-based checks.
- It does not provide confirmed scam detection.
- Voice recordings are not analysed.
- Website safety cannot be guaranteed.

## Conclusion
CyberShield provides basic digital safety awareness and guidance to help users identify suspicious activities and follow safer online practices.
